# Java Number Guessing Game
A simple Java console game where the player tries to guess a randomly generated number between 1 and 100.

## How it works
The program chooses a random number between 1 and 100. The player enters guesses until they find the correct number. The program tells the player if their guess is too high or too low.

## What I used
- Java
- Scanner
- Random
- Loops
- If/else statements

## What I learned
This project helped me practise Java basics, including user input, loops, conditions and random number generation.
